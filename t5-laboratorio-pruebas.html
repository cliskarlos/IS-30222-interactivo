        Recordatorio de fórmulas
        
        V(G) = E − N + 2. Equivale a P + 1, donde P es el número de decisiones simples (if, while, for, cada rama de un else if). V(G) es el número de caminos independientes, es decir, el mínimo de casos para recorrer un conjunto básico de caminos.
